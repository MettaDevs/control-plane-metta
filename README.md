# control-plane-metta

Control plane untuk onboarding, trial gratis 30 hari Praktik Dokter, tenant, lingkungan, rilis, dan agen server. Repo ini akan berisi konsol operator internal dan, kelak, portal customer, yang di-deploy terpisah. Keduanya akan ditulis dengan Bun + Elysia.

## Status

Belum ada kode, jadi belum ada perintah yang bisa dijalankan. Pekerjaan pertama adalah onboarding, yaitu membuat tenant dan lingkungan, karena trial gratis Praktik Dokter membutuhkannya.

Runtime yang dijalankan untuk klinik ada di repo [operations-metta](https://github.com/MettaDevs/operations-metta). Aturan kerja di repo ini ada di [AGENTS.md](AGENTS.md).
